my private blog

This is a private blog: posts live at unguessable links and are shared directly with the people they're meant for. There is no index here — if someone sent you a link, that link is the way in.

On a post you can hit Listen to have the page narrate itself (when the post carries audio), select any passage to leave a comment for the author, and use Copy as Markdown to take the text with you. Treat links you were given as private — anyone holding one can read that post.
