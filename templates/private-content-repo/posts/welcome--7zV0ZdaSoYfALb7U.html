Welcome to your private blog

This post's URL ends in an unguessable token — that token is the whole access-control story, so a link to this page is a key, and sharing the link is sharing the key.

How this stays private

The engine suppresses everything that would enumerate or advertise posts: no sitemap, no feeds, no llms.txt, no landing-page post list, and every response tells search engines not to index it. A build-time audit fails the deploy if any of that ever regresses, and it also rejects any post whose filename lacks the unguessable suffix — create posts with bun run new-post <slug> so the token is generated for you.

If a link ever leaks to someone it shouldn't have, rename the post's file (a new token is a new key), regenerate, and redeploy — the old URL stops resolving. Everything else about the engine works normally here: comments, narration, version history, offline reading.
